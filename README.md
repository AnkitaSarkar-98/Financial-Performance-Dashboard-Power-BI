# Overview

An interactive Power BI Financial Performance Dashboard designed to analyze revenue, profitability, budget performance, cash flow, products/services, and receivables.

# Tools

- Power BI
- Power Query
- DAX

# Method

Power BI – Created interactive dashboards, KPIs, charts, filters, and financial visualizations.

Power Query – Cleaned and transformed the data, created dimension tables, and prepared the dataset for analysis.

DAX – Created measures for Revenue, Budget Variance, Gross Margin %, EBITDA %, Net Cash, and other financial KPIs.

# Conclusion

The dashboard provides a clear view of financial performance and helps identify trends, budget gaps, profitability, and cash-flow position through interactive visuals and KPIs.
